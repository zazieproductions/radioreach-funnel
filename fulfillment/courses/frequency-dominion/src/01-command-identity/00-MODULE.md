# MODULE 01 — COMMAND IDENTITY

> Stop sounding like a fan. Start sounding like a station's problem-solver.

Module 01 is the gate. Nobody sends until the identity sentence is pinned, the clock fits, the proof is true, and the oath is signed.

| # | Lesson | Spoken | Drill |
|---|--------|:------:|-------|
| 01 | [The unheard tax](01-the-unheard-tax.md) | ~9 min | Write five identity-sentence drafts in WB01. Circle one. Pin it above your send list. |
| 02 | [Station as customer](02-station-as-customer.md) | ~8 min | Pick one target format. Write its five constraints. Cut or edit one song to fit the tightest clock. |
| 03 | [Proof before volume](03-proof-before-volume.md) | ~8 min | Write the 4-line proof stack. Any empty line gets a dated action inside 7 days. |
| 04 | [The no-spam oath](04-the-no-spam-oath.md) | ~8 min | Write and sign the no-spam oath. Screenshot it and send it to your accountability human. |
