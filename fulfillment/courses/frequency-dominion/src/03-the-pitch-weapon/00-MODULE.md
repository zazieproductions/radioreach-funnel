# MODULE 03 — THE PITCH WEAPON

> Emails that survive 1.4 seconds of a music director's thumb.

Module 03 builds the weapons: subject lines that survive 1.4 seconds, the 90-word pitch, the one-page EPK, and radio-ready audio.

| # | Lesson | Spoken | Drill |
|---|--------|:------:|-------|
| 01 | [Subject lines that get opened](01-subject-lines-that-get-opened.md) | ~8 min | Write 11 subject lines. Kill 8, keep 3, assign each to first send / Touch 2 / Touch 3. |
| 02 | [The 90-word pitch](02-the-90-word-pitch.md) | ~8 min | Write the 90-word pitch. Read it aloud. Cut until it's under 90 words / 40 seconds. Freeze as v1. |
| 03 | [EPK that does not embarrass you](03-epk-that-does-not-embarrass-you.md) | ~8 min | Build the EPK one-pager (template in the zip). Run the 20-second civilian test. Revise until a stranger can pass it. |
| 04 | [Audio assets for radio](04-audio-assets-for-radio.md) | ~8 min | Export the radio edit + 30-second hook with correct metadata, named to convention, in the one link. Run the busy test. |
