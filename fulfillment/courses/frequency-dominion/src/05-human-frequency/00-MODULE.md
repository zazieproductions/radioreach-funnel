# MODULE 05 — HUMAN FREQUENCY

> Calls, interviews, and relationships that survive one song.

Module 05 is the human layer: the 20-second call, interviews that book the next spin, the thank-you economy, and burned-well repair.

| # | Lesson | Spoken | Drill |
|---|--------|:------:|-------|
| 01 | [When to pick up the phone](01-when-to-pick-up-the-phone.md) | ~8 min | Write the 20-second call script. Record it twice, fix what you hear. Place one green-light call this week. |
| 02 | [Interview that books the next spin](02-interview-that-books-the-next-spin.md) | ~8 min | Write 5 interview answers timed under 40 seconds each, plus the closer question. Read aloud with a timer. |
| 03 | [Thank-you economy](03-thank-you-economy.md) | ~8 min | Write the thank-you email template and the station-first social post format. File both in the swipe file. |
| 04 | [Repairing a burned well](04-repairing-a-burned-well.md) | ~8 min | If you have a burned contact: write the 4-move apology (40–80 words, 90-day pledge) and send it only if true. If not: log your clean-record note. |
