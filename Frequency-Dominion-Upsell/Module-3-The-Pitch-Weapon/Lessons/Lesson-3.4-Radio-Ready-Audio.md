# 3.4 Radio-Ready Audio — The 90-Second Weapon That Forces Replies

> **THE ONE-LINE TRUTH:** A PD doesn't have time to open a streaming link — they have time for a 90-second file that's already cut, already loud, already clean, and already tagged.

## VIDEO SCRIPT (ready to record · runtime ≈ 09:10)

**[0:00 – 0:50] COLD OPEN — face to camera, a file folder tosses on a desk.**
"Here's what you've been sending: a Spotify link. A Dropbox folder. A YouTube URL. A 'SoundCloud in my bio.' Meanwhile the PD is thinking: 'I have to open a player, find the track, hope it loads, and evaluate a song that might not even be radio-loud.' You didn't fail musically. You failed *logistically*. Today we fix the logistics."

**[0:50 – 2:20] THE RADIO-READY PACKAGE — the three-file standard.**
"One package, three files, done upfront. File one: the 90-second radio promo — hook, voice, song, CTA mixed. File two: the 3:00–3:45 radio edit — clean, loud, cut to standard. File three: the 30-second 30/60/90 payload — for station IDs, beds, and social clips. All three in WAV and MP3. All three named [ARTIST]-[SONG]-[EDIT]. That's it. No folders, no zip, no convenience excuses — one attachment, three files, zero thinking for the PD."

**[2:20 – 4:00] THE 90-SECOND PROMO STRUCTURE — on-screen: the 5-act blueprint.**
"Act one (0:00–0:10): the hook — the most undeniable 10 seconds of your song, no intro, no verse, straight to the chorus. Act two (0:10–0:25): the voice drop — a 10-second spoken intro: 'New from [artist], this is [song]...' Act three (0:25–0:50): the second hook — the money moment, louder. Act four (0:50–1:15): the story voice — date, city, venue, one proof line. Act five (1:15–1:30): the CTA — 'Request it on [station], [artist] on all platforms.' Ninety seconds. That's the entire argument."

**[4:00 – 6:00] THE PRODUCTION STANDARDS — the four non-negotiables.**
"One: loudness — radio edit at approx. -14 LUFS short-term, mastered, true peak under -1 dBTP, never a bedroom mix that a PD has to reach for a volume knob. Two: clean edit — explicit words cut in the edit AND in the promo, no second version drama. Three: intro — no more than one bar of musical intro before the hook. Four: ID-tagged metadata — artist, title, contact in the file properties, because files get passed around stations like business cards. Miss any of the four and you are not radio-ready — you're an unpaid demo."

**[6:00 – 7:40] THE DELIVERY MECHANICS — speed is a weapon.**
"Where does it live? (1) The email attachment — 90-sec file only, under 10MB. (2) The one-page EPK embed — one click, no player hunt. (3) The private drive folder with *only* the three files — named, sorted, and linked. Every payload shipped in under 60 seconds of PD effort, or it dies in the decision window. Test your delivery like a stranger: send it to a friend's phone and time how long till the song is playing."

**[7:40 – 8:30] THE REPLY-FORCING QUESTION — the pro move.**
"Close the email with a one-line question that forces a 20-second answer: 'If this fits your [format] block, want the full WAV?' The PD's answer is binary and effortless. You're not asking for a favor — you're asking a customer to confirm delivery. That's the shift. That's the reply."

**[8:30 – 9:10] CLOSE — module card.**
"Your weapon is loaded. Module 4 is the campaign — the 21-day sequence that turns 20 armed stations into adds."

## IMPLEMENTATION DRILLS

- **Drill 1 — The Three-File Package (2–4 hrs).** Produce the 90-sec promo, radio edit, and 30-sec payload. **Pass standard:** three files, professionally named, WAV + MP3, metadata filled, under 10MB each.
- **Drill 2 — The Loudness Audit (20 min).** Check LUFS and true peak. **Pass standard:** radio edit at approx. -14 LUFS, true peak under -1 dBTP, zero clipping, and it doesn't distort on a phone speaker.
- **Drill 3 — The 12-Second Hook Test (15 min).** Time from file start to first chorus hook. **Pass standard:** under 12 seconds or you re-edit.
- **Drill 4 — The 60-Second Delivery Test (15 min).** Send the package to a friend's phone from a cold start. **Pass standard:** song is playing from their phone within 60 seconds using only your link/attachment.

**WAR-ROOM NOTES — 3.4 Radio-Ready Audio**

**THE LOGISTICS GAP IS THE BIGGEST UNTAPPED ADVANTAGE IN INDIE RADIO**

The music that gets added is rarely the best music — it's the music that's *easiest to add*. A PD evaluating one file vs. a folder of five versions, one radio-loud edit vs. a master that's quieter than their station's bed, one 90-second argument vs. an unlabeled Dropbox: the gap isn't talent. It's friction. Radio-ready audio removes 100% of the friction so the decision is purely musical — and you win because your music was never the problem.

**THE THREE-FILE FORMULA IS A SUPPLY-CHAIN, NOT A CHOICE**

- **90-sec promo** — the argument (hook, voice, story, CTA). This is what gets the first listen.
- **Radio edit** — the inventory (clean, loud, 3:00–3:45). This is what actually gets added.
- **30-sec payload** — the derivative (beds, IDs, clips, social cutdowns). This is what the PD *hands to the promotions team* — and the moment a station's promo person forwards your 30-sec cutdown, you've graduated from "submission" to "material."

Produce all three before the first send. Every hour of production here saves 20 hours of campaign repair.

**THE FRICTION SCORE (AUDIT YOURSELF)**

Score each delivery element 0–2: (0) file exists but is buried in a folder; (1) file is linked but requires login/player; (2) file plays in one click with correct name and metadata. A PD-facing friction score of 8+ wins; 5 and below is a coin flip. This single metric predicts reply rate better than any genre or quality metric — because it predicts whether the PD *ever listens*.

**THE 12-SECOND RULE APPLIES TO THE PROMO TOO**

The promo's first 10 seconds are the hook — not an intro, not a "hey everyone," not a fade-in. Radio people sample. The 90-sec file must be sample-able: any 10 seconds of it should be enough to sell the song. If you can't randomly sample it, it's a song trailer, not a weapon.

**THE METADATA GOLD MINE**

Every file carries: artist, title, contact email, phone, city, release date, and a note "clean edit." When a PD forwards your file to a colleague — which they do — the metadata is your follow-up system working for free. A file without metadata is a file that dies on arrival. Tag everything. Always.
